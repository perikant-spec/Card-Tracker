# Fixtures

- `real/`    your exported bank SMS. Git-ignored. Never commit.
- `sample/`  examples that are safe to commit: synthetic messages, or real ones you have
             redacted by hand (names, card numbers, merchants, phone numbers altered).

## Status

`sample/synthetic.jsonl` is **entirely synthetic** (generated by
`tools/gen_synthetic_fixtures.py`). It proves the templates match the wording they were written
for; it does **not** prove that any bank actually words its messages that way. Every issuer
template is an UNVERIFIED TEMPLATE until real samples are added here. See `docs/UNVERIFIED.md`.

## Format

One JSON object per line (`*.jsonl`). `core`'s `FixtureHarnessTest` reads every file in `sample/`.

    {"sender": "VM-HDFCBK", "date_ms": 1794724200000, "issuer": "HDFC",
     "body": "Rs.1,250.00 spent on HDFC Bank Card x1111 at FAKEMART STORE on 15-11-26",
     "expect": {"result": "parsed", "type": "PURCHASE", "amount_paise": 125000, "last4": "1111",
                "auth": false, "reversal": false, "merchant": "FAKEMART STORE", "date": "2026-11-15"}}

- `sender`, `date_ms`, `body` are what `tools/extract_fixtures.py extract` writes.
- `issuer` picks the template set: HDFC, ICICI, SCAPIA, KIWI, SBI, AXIS.
- `expect.result` is `parsed`, `ignored` (OTP, promo, bank-account alert: dropped, never stored)
  or `unparsed` (goes to the review queue).
- Other `expect` keys are optional and only checked when present: `type`
  (PURCHASE/FEE/PAYMENT/REFUND), `amount_paise` (integer), `last4`, `auth`, `reversal`,
  `merchant`, `date` (yyyy-mm-dd), `ref`, `template`, and for statement notices
  `statement: {total_due_paise, min_due_paise, due_date}`.
- Numbers must be integers. Money is paise; a fractional number is rejected by the reader.

## Adding real samples

1. `python3 tools/extract_fixtures.py list-senders <export.xml>` and note the sender IDs.
2. `python3 tools/extract_fixtures.py extract <export.xml> --senders '...' --out fixtures/real`
3. Read `fixtures/real/redacted.jsonl` yourself, alter anything personal that is left, add the
   `issuer` and `expect` keys, and copy only those lines into a new file under `sample/`.
4. Run `./gradlew :core:test`. A failing line means the template needs editing
   (`core/src/main/kotlin/tracker/core/parsers/`), not the expectation.
